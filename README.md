# The Ninth Signal
A short original evidence mystery. Six records and one dispatch decision at a fictional coastal station.

[Play free in your browser](https://cinemin.github.io/ninth-signal/) · [Download the offline ZIP](https://cinemin.github.io/ninth-signal/ninth-signal-0.1.1.zip)

Open the records, compare their timestamps, then decide where the launch should go. Three explained outcomes; no timer. Contains fictional evacuation peril without graphic violence. This is entertainment, not emergency training.

Keyboard: Tab between controls; Enter to activate. Progress lasts while the page is open; reload starts again. No account, analytics or application data collection. GitHub hosts the online page and processes normal web requests; the downloaded HTML runs offline.
